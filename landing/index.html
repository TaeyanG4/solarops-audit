화면의 발전량은 실측값인가요?

유효한 15분 전력에 시간 간격을 적용한 추정 에너지입니다. 원본 보간값이 포함될 수 있습니다. 계량기 실측 전력량, 매출, 확정 손실로 해석하지 않습니다.

설비 고장을 자동 확정하나요?

저출력 조건에 해당하는 구간을 사람이 확인할 검토 후보로 표시합니다. 현장 고장 정답과 탐지 정확도는 검증하지 않았으며, 후보가 없다는 결과도 설비 정상의 보증은 아닙니다.

어떤 데이터를 사용하나요?

이 페이지의 분석 화면은 BR-PVGen 공개 역사 자료입니다. 별도 ONS 수집 기능은 원문 시각과 MWmed 단위를 보존하며, 기존 추정 kWh에 합산하지 않습니다. 실패·재처리 시험에는 명시된 합성 자료를 사용합니다.

지금 직접 실행해 볼 수 있나요?

저장소 접근 권한과 Python 3.12가 있으면 로컬에서 합성 7일 데모를 실행할 수 있습니다. 공개 원본 전체 다운로드나 Docker 없이 실패·재처리·보고서 생성 흐름을 확인합니다. 로컬 데모 실행 안내

현재 서비스 제공 범위는 어디까지인가요?

현재는 로컬에서 실행·검증한 엔지니어링 포트폴리오입니다. 고객 인증, 실제 설비의 실시간 연결, 공개 서비스 운영은 제공 범위에 포함되지 않습니다. 실제 고객·매출·고장 탐지 정확도에 대한 성과는 제시하지 않습니다.
