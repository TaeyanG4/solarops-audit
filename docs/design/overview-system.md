# 전체 현황 디자인 시스템

대상: FastAPI가 제공하는 `dashboard.html`과 `static/dashboard.css`, `static/dashboard.js`.
2026-10-23, H-A-12. API·계산 버전은 v0.4.1 / energy-interval-v2 그대로 유지합니다.

## 사용 장면과 결정

운영 담당자가 밝은 업무 환경에서 역사 자료를 월별로 검토하는 읽기 전용 화면입니다. 첫 질문은 “얼마를 추정했는가”, “어느 정도를 신뢰할 수 있는가”, “어느 발전소를 확인할 것인가”입니다. 실시간 발전 상태나 확정 고장·손실을 암시하지 않습니다.

[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)의 `energy operations analytics dashboard` 디자인 시스템 검색과 `analytics dashboard data quality` 재검색을 사용했습니다. 자동 추천의 landing / enterprise gateway 패턴은 제품 화면에 맞지 않아 채택하지 않았습니다. **일반 가이드로 전환**해 Minimalism / Swiss 스타일의 정보 위계, 조밀한 데이터 화면, 대비·키보드·반응형 지침을 적용했습니다. 시계열 가이드의 수치 탐색과 표 대체 경로를 일별 합계에 맞는 막대 차트로 구현했습니다.

[Impeccable](https://github.com/pbakaus/impeccable)의 context, craft-floor, operate, audit, polish 지침을 적용했습니다. 기술 검수와 구현 보완을 수행했으며 두 에이전트의 독립 critique를 수행한 것으로 표현하지 않습니다.

## 시각 규칙

| 요소 | 결정과 이유 |
|---|---|
| 작업 영역 | `--paper #f4f6f7`, 흰색 surface. 밝은 사무 환경의 장시간 수치 검토 |
| 탐색 | `--nav #152d35`, 활성 메뉴 `#26434a`. 작업 영역과 탐색을 구분 |
| 추정 에너지·유효값 | `--green #22765c`, 강조 `#15533f` |
| 무효값 / 누락 | 황갈색 `#916018` / 슬레이트 `#6a7786`, 텍스트와 사각형·점선 병행 |
| 원본 보간 | 자주색 `#655286`와 별도 설명 영역. 품질 분류에 합산하지 않음 |
| 타이포그래피 | Segoe UI / Malgun Gothic. 한국어 로컬 실행과 외부 폰트 요청 없는 재현성을 우선. 본문14px, 표14px/헤더13px, 축12px, 제목30px, KPI32px. 숫자 tabular-nums |
| 간격·윤곽 | 기본24px, 작업 여백32px, 패널12px radius, 1px border. KPI는 하나의 요약 띠와 구분선 |
| 입력 | 기본44px 이상, focus ring3px, 네이티브 month/select 유지. 작은 차트 막대에는 동등한 날짜 선택/이전·다음 경로 제공 |
| 모션 | 버튼160ms 상태 전환과 기존 로딩 표시만 사용. reduced-motion에서 정적 상태 유지 |
| 아이콘 | 직접 작성한 일관된1.7px 선 SVG. 텍스트 옆 장식은 aria-hidden |

밝은 테마만 제공하며 다크 테마 지원을 주장하지 않습니다. 기존 관측 화면의 차트와 생성된 보고서 본문은 이번 리디자인 범위에서 제외됩니다.

## 정보와 상호작용

- 상단: 현재 화면 → 월·자료 필터 → 월별 운영 현황 → KPI → 일별 추정/품질 → 발전소 검토 순서.
- KPI: 추정 MWh, 유효값 비율, 무효 슬롯(누락 수 별도 표기), 조회 발전소/월 전체 파티션 확보 수. API 값의 단위·반올림 외 재계산 없음.
- 자료 품질: 유효/무효/누락은 슬롯 분류, 원본 보간은 겹칠 수 있는 별도 속성. 원본 보간 여부 불명 수를 함께 표시합니다. 미등록 날짜는 품질 비율 분모에 자동 포함되지 않는다고 명시합니다.
- 일별 차트: 날짜별 발전소 수가 다를 수 있는 합계입니다. hover/click/focus, 방향키/Home/End, 날짜 select, 이전/다음으로 같은 수치 패널을 갱신합니다. 수치 표는 details로 펼칩니다.
- 자료 없는 날짜는 점선과 “자료 없음”으로, 실제0은0수치와 바닥 막대로 표시합니다. 임의 보간하지 않습니다. API가 null을 주는 경우 “추정값 없음”을 표시하고0으로 바꾸지 않습니다.
- 발전소: 유효값 비율 오름차순 유지, ID검색과 결과 수, ID가 포함된 상세 버튼 이름. 순위는 설비 고장 순위가 아닙니다.
- 오류: 요청 실패/시간 초과 안내와 다시 시도. 빈 월/검색 결과 없음/부분 기간을 각각 표시합니다.

## 반응형

| 너비 | 구성 |
|---|---|
| 1440px | 좌측 탐색, 4열 요약, 차트/품질2열, 수치 정렬된 표 |
| 768px | 상단 탐색, 2열 요약, 세로 차트/품질, 2열 발전소 요약 |
| 390px | 상단3메뉴, 2열 요약, 고정12px 축 글자, 1열 발전소 요약과 노출된 상세 버튼 |

표의 원래 table/th/td 구조와 column header는 유지하며 작은 화면에서 CSS로 재배치합니다. 축 글자는 SVG 전체와 함께 축소하지 않습니다. 이후 정적 파일을 변경할 때는 HTML의 자산 버전 query도 갱신해 이전 캐시와 섞이지 않게 합니다.
