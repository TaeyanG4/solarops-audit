## 추가 확정 요건 — 보고서와 입력 컨트롤

- 사용자는 작은 글씨, 기본 월/목록 선택창, 옛 보고서 양식과 페이지 안의 페이지 구조를 거절했다. 본문 16px, 표·설명·조작 최소 14px로 조정한다.
- 보고서는 별도 iframe 없이 메인 문서에 요약 → 품질 정의 목록 → 펼치는 일별 내역 → 검토 후보 → 원본 계보 순서로 읽는다. 페이지 전체 스크롤 하나를 사용하며 표의 가로 탐색만 허용한다.
- 인쇄용 독립 HTML은 같은 report.css·Pretendard·추정/품질 용어를 사용한다. 원래 UUID의 출력물은 보존하고 새 보고서를 생성한다.
- 선택창은 보이는 레이블, 키보드 탐색, 선택/비활성 상태, 포커스 복귀를 갖춘 공통 컴포넌트로 통일한다. SVG favicon은 기존 번개 기하를 사용한다.
- 검수는 사용자 첨부 보고서/월 선택창 이미지와 최신 3너비 실제 캡처를 함께 비교한다. 이전 수평 탐색안의 검수 결론을 이번 범위에 재사용하지 않는다.

## 후속 상호작용 계약 — UI-04

- 시스템 관리 중간 페이지를 제거한다. 사이드바의 실제 href는 독립8504로 연결하고 기존 system 주소도 이동한다. 월·출처를 전달하며 서비스 제어 / 컨테이너 상태 / 운영 안내 탭으로 작업을 구분한다.
