# ADR 0004 — quality and atomic publication

수락. 각 파티션의 raw는 조직별 SHA-256 경로로 불변 보존합니다. 매 실행은 staging UUID 경로에 Parquet/시계열을 작성하고 업로드한 뒤 DB 트랜잭션에서 지표·이슈·사건·active manifest를 같이 반영합니다. 롤백 시 이전 활성 run_id가 유지됩니다. 실패 staging은 보존하고 보고서에서는 읽지 않습니다.

동일 source_version에 다른 입력 해시를 연결할 수 없습니다. PostgreSQL advisory lock으로 같은 파티션/소스 버전의 경쟁 갱신을 직렬화합니다. 수정 자료는 명시적 새 버전으로 들어갑니다. 이전 원본과 결과는 남습니다. 날짜별 커밋이므로 여러 날짜 재처리의 중간 실패 시 성공한 날짜는 유지되고 실패 날짜만 다시 처리합니다.

파일 종류와 보간 정보는 현장 고장 라벨이 아닙니다. 실제고장 정확도/원화손실은 계산하지 않습니다. 일별 끝의 15분 해석과 관측 범위 분모는 데이터 계약에 명시합니다.
