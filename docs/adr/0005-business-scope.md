# ADR 0005 — local pilot preparation

수락. P0는 승인된 공개 자료 및 합성 파일만 사용합니다. 고객 업로드·이메일·결제·다중 사용자 인증·공개 서비스는 만들지 않습니다. 단일 조직을 서버 설정에 고정하되 모든 쿼리/객체 경로에 org 경계를 둡니다.

가격, 절약 시간, 수익은 가설이며 인터뷰나 매출 실적으로 표시하지 않습니다. 파일럿 준비 문서와 가격 시뮬레이터를 제공합니다. 실제 고객 연락·계약·결제·데이터 사용은 사람의 별도 결정입니다.

첨부된 M0-only 예시와 단계별 중단 문구는 전체 프로젝트 완성을 요청한 현재 사용자 지시를 제한하지 않습니다. 기존 ZIP/파일은 보존하며 민감 자료 삭제, 외부 전송, 공개 게시를 하지 않습니다.
