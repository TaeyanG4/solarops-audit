# 계산 v2와 기존 결과 보존

수락, 2026-10-22. `energy-interval-v2`는 모두 무효인 전력 슬롯의 0→null 표현과 현지 날짜/UTC 원본 경계의 불필요한 빈 파티션을 수정한다. 품질·후보·시계열도 논리 해시에 포함해 파생 산출물 변경을 감지한다. 에너지 산식은 변경하지 않는다.

같은 계산 버전으로 기존 결과를 덮어쓰면 과거 보고서와 현재 화면을 대조하기 어렵다. 카탈로그의 계산 버전 키로 v1과 v2를 별도로 유지하고 v1 기준 목록을 보존한 뒤 v2를 적재한다. 일별 수치·원본 SHA와 표본 시계열을 비교한 후 앱 이미지를 전환한다. 버전과 해시 구성 변경으로 두 버전의 논리 해시는 달라야 한다.

보고서는 생성 당시 스냅샷이며 기존 HTML/CSV/manifest는 수정하지 않는다. 새 보고서를 만들면 active report 포인터가 이동하지만 이전 report ID도 남는다. 앱은 코드에 고정된 계산 버전을 조회한다. 따라서 네이티브·Compose·kind 카탈로그 각각 필요한 자료를 v2로 처리해야 하며 코드 업그레이드만으로 기존 v1 데이터가 v2로 조회되지는 않는다.

회귀: `tests/test_calculation_v2.py`. 공개 비교: `scripts/validation/compare_calculations.py`. 구버전 이미지로 되돌리면 남아 있는 v1 파티션을 조회할 수 있으나 active report는 독립된 포인터이므로 보고서 계산 버전도 확인한다. DB/원본/산출물 삭제는 필요하지 않다.
