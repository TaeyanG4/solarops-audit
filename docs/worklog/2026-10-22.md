# 2026-10-22 작업 기록

이 문서는 기존 실행 기록을 영역별로 정리한 요약입니다. 새로 재실행한 결과가 아니며, 원문은 [이전 handoff](archive/2026-10-23-handoff.md)와 [이전 discoveries](archive/2026-10-23-discoveries.md)에 보존했습니다.

## 초기 구현과 공개 자료 처리

- 수집·계약 검증·일별 정규화·품질 분석·월간 보고서·API와 공통 CLI를 구현했습니다.
- BR-PVGen 51개 발전소, 인버터 14,400,480행, 12,572개 일별 파티션을 처리하고 native와 PostgreSQL/MinIO 결과를 비교했습니다.
- Compose·Airflow·kind/KPO, 실패 재시도와 작은 합성 작업의 자원 동작을 확인했습니다. 작은 작업 측정을 대규모 확장성으로 해석하지 않습니다.
- 근거: [초기 전체 검증](../benchmarks/2026-10-22.md), [구조](../architecture/system.md), [데이터 계약](../data-contract.md).

## 월별 조회와 v0.3 유지보수

- 월별 읽기 모델과 단일 조회로 기존 요청 패턴을 53회에서 1회로 줄였습니다.
- 같은 로컬 조건의 5회 중앙값은 703.239ms → 12.576ms였습니다. 응답 범위와 요청 방식이 달라 일반적인 성능 배수로 주장하지 않습니다.
- 스크립트·패키징·문서 링크와 운영 경로를 정리했습니다.
- 근거: [조회 측정](../benchmarks/workspace-v0.3.0.md), [v0.3.1 유지보수](../benchmarks/maintenance-v0.3.1.md).

## 계산 v2·진단·복원

- 음수·NULL·시간 간격·표본 수 등 계산 경계를 수정하고 `energy-interval-v2`로 분리했습니다. 이전 결과를 보존하며 공개 서비스 자료를 재처리했습니다.
- 읽기 전용 진단 CLI와 합성 자료의 별도 경로 복원, PostgreSQL/MinIO 논리 복원 시나리오를 확인했습니다.
- 전체 공개 v1/v2 일별 지표·입력 SHA 일치를 확인하고 서비스·이미지·CI 증거를 남겼습니다. 실제 호스트 유실 재해복구 검증은 아닙니다.
- 근거: [v0.4 검증](../benchmarks/reliability-v0.4.0.md), [계산 버전 결정](../adr/0007-calculation-v2.md), [복원 절차](../runbooks/backup-restore.md).
