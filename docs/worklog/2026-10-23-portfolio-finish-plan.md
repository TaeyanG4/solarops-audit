## 남은 계획과 종료 조건

- [plan](../../plan.md)에 PORT-01 문서 일치22점 → PORT-02 수집 상태 화면20점 → PORT-03 최종 재현19점 → PORT-04 제출 자료18점을 미착수로 등록했습니다. 후속 재현/캡처는 최종 화면 이후에 수행하도록 의존성을 지정했습니다.
- 4개 완료 시 이번 **취업 포트폴리오 제출 범위**를 완료합니다. 새 요구가 없으면 Kafka/Spark·상용 운영·고객 영업을 계속 추가하는 방식으로 종료 조건을 바꾸지 않습니다.
- 기존 클린 checkout CI·복구 데모를 재사용하고 최종 변경 동작만 일회성으로 확인합니다. 단발성 UI 회귀 테스트나 별도 검증 스크립트를 기본 추가하지 않습니다.
- 이번 변경은 계획·현재 인계·문서 목차에 한정합니다. 앱·수집 일정·데이터·컨테이너는 변경하지 않았고 제품 기능을 완료했다고 기록하지 않았습니다. 문서 링크707개·스크립트 참조75개·원본 checksum8개와 `git diff --check` 통과, handoff40줄·최근 요약8개를 확인했습니다. 앱 테스트는 다시 실행하지 않았습니다.
