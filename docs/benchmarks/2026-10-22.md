## 해결한 환경 문제와 한계

- MinIO 공개 이미지와 바이너리 다운로드 실패 → 고정된 공식 소스 빌드.
- Airflow 3.3 DagBag API와 safe-mode 검색 조건 → 실제 import 검사 후 수정.
- kind local-path RWX 불가 → 별도 RWO 로그 PVC, 기존 Pending PVC는 보존.
- 빈 Compose 볼륨의 소유권 초기화 → 서비스 UID 통일 및 초기화 marker.
- Windows/WSL 가상환경 혼용 → `.venv` / `.venv-linux` 분리. 기존 Windows 환경은 locked 의존성으로 복구 후 재검사.
- Windows/WSL SQLite WAL 동시 열기 → Make는 `data/linux-native`에 별도 로컬 DB 사용.
- Linux 테스트의 혼합 줄바꿈 fixture → CSV writer로 일관되게 작성. CSV 품질 검사를 완화하지 않음.
- Starlette TestClient의 httpx 사용 deprecation warning 1개가 남으며 검사 실패는 아닙니다.
- 초기 로컬 검증 이후 사용자 요청으로 비공개 GitHub 저장소를 생성했습니다. [첫 원격 CI](https://github.com/TaeyanG4/solarops-audit/actions/runs/39762639462)에서 설치/lint/테스트/합성 데모/lockfile 검사가 성공했습니다. 독립 외부 세션 리뷰, 고객 인터뷰/계약/결제, 실제 고장 정확도 검증은 미수행입니다.
