# 합성 실행 이력 지연의 역사 표본

27조건·1,080개 요청의 지연(ms)·성공 여부만 보존합니다. 발전소 자료 원문·DSN·자격증명·컨테이너 환경은 없습니다. 기존 원본 JSON과 probe는 Git 제외 artifacts에 보존하며 그 SHA256을 provenance에 기록했습니다. 수정 전720/후360건, 각조건40건이며 p50은 median, p95는 정렬38번째(ceil(0.95*40))를 소수둘째자리로 반올림합니다. 이 식으로 모든 행의 요약과 일치함을 확인했습니다.

신규 성능 실측이 아닙니다. [당시 버전·측정 조건·표](../../technical-20261023.md)의 수치를 독립적으로 재계산하는 증거입니다. 동일 호스트·순차 측정·캐시·동시8 한계는 그대로입니다. probe 해시만으로 실행 스크립트나 환경을 복원할 수 있다고 주장하지 않습니다.
