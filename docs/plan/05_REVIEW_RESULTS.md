## B. 아직 남은 구현 단계의 Blocker/조건부 승인 사항

1. **실제 CSV/ZIP의 전체 컬럼과 데이터 형식 확인 필요:** 현재는 공식 Readme와 공개 metadata CSV를 교차검증한 기획 단계다. M1에서 적어도 각 ZIP의 한 CSV를 읽고 알려진 컬럼/실제 데이터 타입을 검증해야 M2를 시작한다.
2. **Airflow/Helm/Provider 버전 호환 검증 필요:** Airflow 3 Task SDK/Helm/KPO가 모두 기술적으로 문서화되어 있지만, 동일한 조합의 실제 설치 테스트는 하지 않았다. M5/M6에서 최소 예제를 실행하고 버전을 고정한다.
3. **비용/고객 효과 미검증:** 4주 20만 원과 월 15~30만 원은 실험 가설이다. 실제 유료 고객의 지불 의사와 절약 시간이 증명되지 않았다.
4. **실제 고장 라벨이 없음:** synthetic fault injection은 코드 테스트이지 실제 현장 고장 정확도 검증이 아니다. UI에서 '고장 확정' 또는 '예상 손실액' 출력 금지.
5. **개발자 PC 사양 미확인:** 사양 확인 전 K8s 전체 스택이 로컬에서 무조건 실행된다고 약속할 수 없다.
6. **데이터 보존·삭제·고객 동의 요건:** 실제 고객 파일은 기술적으로 읽을 수 있어도 사용 허가·보안 설계 없이 수령하지 않는다.
