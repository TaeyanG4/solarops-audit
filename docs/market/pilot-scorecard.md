# 파일럿 측정 양식

실제 기록 전 빈 양식입니다. 아래 칸의 `미측정`을 0으로 계산하지 않습니다. 고객 식별자와 실제 파일은 이 공개/합성 개발 저장소에 넣지 않고 합의된 비공개 보관 위치에서 관리합니다.

| 항목 | 기록 |
|---|---|
| 익명 파일럿 ID / 담당자 / 기간 | 미측정 |
| 자료 이용 권한·보관/반환 합의 위치 | 미확인 |
| 발전소 수 / 파일 형식 수 / 자료 기간 | 미측정 |
| 전력·에너지 단위 / 측정 간격 / 시간대 | 미확정 |
| 기존 보고 업무와 도구 / 보고 1회 소요시간 | 미측정 |
| 초기 연결·계약 확인·회귀 검증 시간 | 미측정 |
| 수집·처리·검수·수정·납품 시간 (각각) | 미측정 |
| 수정 횟수와 요청 내용 | 미측정 |
| 초기 구축 견적 / 계약 / 실제 입금 | 미측정 (각각 분리) |
| 반복 납품 견적 / 계약 / 실제 입금 | 미측정 (각각 분리) |
| 노동 단가 / 호스팅·직접비 / 영업비 / 고정비 배분 | 미측정 |
| 고객 검수 통과 / 절약 시간 / 재구매 주문 | 미확인 |
| 납품 보고서 ID / 계산 버전 / 원본 checksum 근거 위치 | 미측정 |

계산: 절약 시간 = 같은 범위의 기존 고객 작업시간 − 도입 후 고객 작업시간. 서비스 제공자의 작업시간과 혼동하지 않습니다. 초기 연결비 회수와 반복 기여이익은 별도 계산합니다. 결과가 음수이거나 미측정이면 그대로 기록합니다.

반복 기여이익 = 실제 반복 매출 − 제공 작업시간×노동 단가 − 직접비. 초기 개발·영업·세금·고정비까지 포함한 전체 손익도 별도 확인합니다. 계산 도구는 `uv run python scripts/demo/pilot_price.py --revenue 200000 --hours 4 --hourly-cost 25000 --hosting 20000`이며 출력은 입력 가정의 산술입니다.

최종 판정: `진행 / 범위·가격 수정 / 중단 / 판단 보류` 중 하나와 이유·다음 검증을 기록합니다. 미리 성공 상태를 채우지 않습니다.
