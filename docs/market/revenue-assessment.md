# 수익화 판단과 첫 유료 파일럿

기록일: 2026-10-22. 사용자와의 판단을 보존한 문서이며 실제 시장조사·수주 실적이 아닙니다. [파일럿 범위](pilot.md) · [측정 양식](pilot-scorecard.md)

## 현재 판단

기술 MVP는 유료 파일럿을 제안할 기반입니다. 수요와 수익성은 아직 검증하지 않았습니다. 첫 상품 후보는 고객이 권한을 가진 CSV를 받아 사람이 검수한 데이터 품질·월간 보고서를 납품하는 서비스입니다. 고객이 직접 가입·업로드하는 SaaS는 인증·권한·업로드·백업 복원 등 추가 작업이 필요합니다.

구매 이유 후보는 여러 제조사 파일을 합치는 시간 절약, 잘못된 수치의 발견, 결과의 원본 추적입니다. 이미 사용하는 모니터링 보고서가 충분하다면 구매 이유가 약합니다. Airflow·Kubernetes 사용이나 테스트 통과는 지불 의사의 증거가 아닙니다.

실제 고장 진단, 확정 발전 손실액, 정산 계량값과 성능보증은 현재 판매 범위에 포함하지 않습니다. 브라질 공개 데이터 검증을 국내 고객 파일 정확성으로 일반화하지 않습니다.

## 원가 가정

20만원은 시장가격이 아닌 초기 가격 가설입니다. 노동을 무료로 계산하지 않습니다.

| 매출 / 노동 단가 / 기타 직접비 | 처리·검수 4시간 | 처리·검수 12시간 |
|---|---:|---:|
| 200,000원 / 25,000원·시간 / 20,000원 | 노동비 100,000원 | 노동비 300,000원 |
| 위 비용을 뺀 기여이익 | 80,000원 | −120,000원 |

세금, 초기 개발, 고객 획득, 고정비는 위 표에 포함하지 않았습니다. 반복 납품 손익분기 작업시간은 `(매출−기타 직접비)/시간당 노동비`로 이 가정에서 7.2시간입니다. 초기 어댑터 개발·영업 비용까지 넣으면 허용 시간은 줄어듭니다.

초기 파일 형식 연결·검증 비용과 반복 보고서 비용을 분리합니다. 표본의 단위·간격·시간대·컬럼을 보기 전에 고정 구축 가격이나 수익을 약속하지 않습니다. 실제 파일럿은 구축비 회수 여부와 반복 납품 기여이익을 각각 기록합니다.

## 첫 판매 실험

1. 사용자가 승인한 대상과 방식으로 반복 보고 업무 담당자 3–5명의 업무·시간·기존 도구·예산 결정을 확인합니다. 이 문서 작성 중 고객에게 연락하지 않았습니다.
2. 자료 이용 권한이 확인된 표본으로 연동 가능성과 소요 시간을 확인합니다. 시각대 없는 값이나 단위·보간 여부를 추측해 채우지 않습니다.
3. 첫 범위는 발전소 1–3개, CSV 한 형식, 한 달 자료, 보고서 한 번과 수정 한 번입니다. 추가 형식·추가 수정·결측 복원은 별도 합의합니다.
4. 기존 보고 시간과 실제 제공 시간을 측정하고 결제, 검수, 다음 달 재구매를 구별해 기록합니다. 관심 표현만으로 수요가 검증됐다고 결론 내리지 않습니다.

## 진행·수정·중단 기준

- 기술 착수: 승인된 표본, 단위·시간대·간격 계약, 정확성 경계 회귀와 별도 복원 시험이 준비되어야 합니다.
- 파일럿 완료: 합의 산출물을 검수받고 작업시간·비용·수정횟수와 실제 지급 여부를 기록합니다. 결제 전 금액은 견적/계약 금액입니다.
- 반복 진행: 고객이 절약 효과를 확인하고 반복 납품의 기여이익이 양수이며 재구매 의사가 실제 주문으로 이어지는지 확인합니다. 초기 개발비 회수 기간도 별도 계산합니다.
- 범위/가격 수정: 데이터 정리에 예상보다 시간이 들거나 추가 형식·수정 요청으로 손익분기 시간을 넘으면 범위나 가격을 재협의합니다.
- 중단: 이용 권한이 불명확하거나 단위·시간대 계약을 확정할 수 없거나, 고객에게 추가 가치가 없으면 자료 처리를 진행하지 않습니다.

현재 인터뷰·실제 고객 표본·계약·결제·절약 시간·재구매 실적은 모두 없습니다. 후속 업무 순서는 저장소 루트 [plan.md](../../plan.md), 실행 기록은 [handoff.md](../../handoff.md)에 남깁니다.
