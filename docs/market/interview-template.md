# 인터뷰 기록 양식

- 인터뷰 날짜 / 동의 범위 / 비식별 업체 코드:
- 관리 발전소 수 / 보고서 책임자 / 구매 결정자:
- 지난달 CSV를 받은 시스템과 실제 작성 과정:
- 최근 누락·보고서 수정·점검 누락의 구체 사례:
- 기존 제품과 이미 해결된 부분:
- 월 업무시간(자기보고인지 관찰값인지 표시):
- 실제 파일 제공 권한 / 보안 조건:
- 파일럿 필수 산출물 / 지불 의향의 근거:
- 고객이 거절한 이유 / 대체 행동:
- 후속 연락에 대한 명시적 동의:

제안 기능에 대한 칭찬을 구매 의사로 기록하지 않습니다. 결제/계약 상태는 사실 그대로 분리합니다. 연락처와 실제 CSV는 이 저장소에 넣지 않습니다.
