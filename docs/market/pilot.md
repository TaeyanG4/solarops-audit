# 파일럿 제안 준비 — 아직 검증되지 않은 가설

대상: 여러 발전소의 제조사 CSV를 합쳐 월간 보고서를 작성하는 국내 소규모 O&M 업체. 제안: 원본을 보존하고 자료의 누락/보간/무효값과 검토 후보를 구분하며 월간 보고서의 근거를 남깁니다.

첫 가설 상품: 발전소 1–3개, 고객이 권한을 가진 CSV 한 형식·한 달 자료, 월간 보고서 1회와 수정 1회. 초기 기획의 최대 10개 범위를 수작업 원가를 확인할 수 있게 축소했습니다. 20만 원은 가격 실험 가정이며 초기 파일 연결비는 표본 검토 후 별도로 산정합니다. 월 15~30만 원도 검증되지 않은 후속 가설입니다. 계약·매출·시간 절약 실적은 현재 **없음**입니다.

[수익화 판단·원가·중단 기준](revenue-assessment.md)과 [파일럿 측정 양식](pilot-scorecard.md)을 함께 사용합니다.

전달 산출물: HTML/CSV 보고서, 품질 이슈 목록, 원본 SHA-256·규칙 버전·재처리 이력, 사람이 검토할 구간. 고장 확정, 정산용 계량값, 발전 손실액, 성능보증, 원격 설비 제어는 제공하지 않습니다.

인터뷰 기록은 `interview-template.md`, 스키마 대응은 `schema-mapping.csv`를 사용합니다. 가격과 원가는 `uv run python scripts/demo/pilot_price.py --revenue 200000 --hours 4 --hourly-cost 25000 --hosting 20000`으로 계산할 수 있습니다. 계산 결과는 입력 가정의 산술이며 판매 예측이 아닙니다.

시작 전 사람이 확인할 내용:

- 제공자가 데이터 소유·이용·제공 권한을 보유하는지 서면으로 확인.
- 목적, 항목, 수신자, 보관 위치, 보존 기간, 삭제·반환 책임자와 사고 연락을 합의.
- 설비의 좌표/운영자 연락처/계약정보/계정정보를 최소화하고 테스트 자료와 분리.
- 원본을 외부 LLM, 공개 Git, 개인 클라우드로 전송하지 않음.
- 보고서의 추정/검토 대상/판단 불가/부분 기간 표시를 담당자가 이해하는지 검수.
- 승인된 고객 어댑터, 인증/조직 권한, 암호화 백업, 복원 시험 후 운영 도입.

사업 완료 조건은 인터뷰 10건, 실제 데이터 권한 확인, 유료 제안/결제 시도, 제공 원가 측정입니다. 여기서는 준비물만 작성했고 연락이나 계약을 실행하지 않았습니다.
