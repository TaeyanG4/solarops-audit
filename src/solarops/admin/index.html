관리 범위와 종료 방법

작업 환경 시작
PostgreSQL → MinIO → 대시보드 순서로 준비 상태를 확인합니다. Airflow·Kubernetes는 필요할 때 별도로 시작합니다.
작업 환경 중지
SolarOps의 Compose 서비스와 kind 노드를 중지합니다. 진행 중 작업은 중단될 수 있으며, 데이터와 볼륨은 보존됩니다.
Kubernetes
별도의 DB·MinIO·Airflow를 포함하는 SolarOps kind 환경 전체를 시작·중지합니다. 위 개별 DB·저장소·Airflow 버튼은 Compose용입니다. 노드 컨테이너 실행은 Kubernetes API·Pod의 준비 완료를 보장하지 않습니다.
관리 서버까지 종료
이 화면은 별도 Python 프로세스입니다. 실행 터미널의 Ctrl+C 또는 프로젝트의 scripts/ops/admin.ps1 stop으로 종료하세요. 종료 후에는 화면에서 서비스를 켤 수 없으므로 같은 스크립트의 start로 다시 엽니다.
안전한 제어 범위
Docker Desktop 엔진과 다른 프로젝트는 유지됩니다. 임의 명령·SQL·데이터 삭제는 제공하지 않습니다. 이 PC의 신뢰할 수 있는 사용자 전용이며 인터넷에 공개하지 않습니다.
